PROPERTY DATA MAKER

物件CSV作成ツール

物件マップに取り込むデータを作成します。初期設定ではCSV形式の文字列をコピーします。

物件情報を入力

物件を複数登録して、一括でCSVデータにできます。

手入力モード

SUUMOの物件URLから読み取る

SUUMOの物件詳細ページの表示構造に合わせて、タイトル・価格・間取り・住所・面積・交通を抽出します。

URLモード

SUUMOの物件詳細ページURLを入力してください。

自動取得ができない場合

ページをブラウザで開き、ページ内の文字をコピーして貼り付けてください。SUUMOの「物件詳細情報」にある価格・間取り・面積・住所・交通を解析します。

読み取った内容（確認・修正して追加）

CSVにする物件 0

追加した物件をまとめて出力します。

まだ物件が登録されていません。上のフォームから追加してください。
出力方法
CSV形式データ

タイトル → 間取り → 価格 → メモ → 住所 → URL

URLから取得した場合は、取得元の物件ページURLもCSVに含めて出力します。

初期設定はコピーです。出力方法を切り替えられます。

※コピーしたデータは、物件比較用マップツールの「CSVから追加」に貼り付けて読み込めます。住所は番地まで入力すると地図上の位置が正確になります。

登録データはこのブラウザ内だけで処理され、サーバーには保存されません。URLの読み取りには外部の読み取りサービスを利用します。URLから取得した物件は、取得元の掲載URLもCSVに記録します。
