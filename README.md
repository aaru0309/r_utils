# HTML便利ツール

個人用HTMLツールをまとめた静的サイトです。ビルド工程は不要で、GitHub Pagesなどの静的ホスティングにそのまま配置できます。

## 収録ツール

- 予定作成ツール
- 費用集計ツール
- 単価比較計算ツール
- 物件比較用マップツール
- 物件CSV作成ツール

## フォルダー構成

```text
index.html                         # ツール一覧・GitHub Pagesの入口
予定作成ツールフォルダ/
├─ 予定作成ツール.html
├─ css/style.css
└─ js/app.js
費用集計ツール/
├─ 費用集計ツール.html
├─ css/style.css
└─ js/app.js
単価比較計算ツール/
├─ 単価比較計算ツール.html
├─ css/style.css
└─ js/app.js
物件比較用マップツール/
├─ 物件比較用マップツール.html
├─ css/style.css
└─ js/
   ├─ app.js
   └─ backup.js
物件CSV作成ツール/
├─ 物件CSV作成ツール.html
├─ css/style.css
└─ js/app.js
README.md
```

各ツールのHTMLに埋め込まれていた主要なCSSとJavaScriptは別ファイルに分けています。動作に必要な一部の動的な `style` 属性や、共通ナビゲーション用の小さなCSSはHTML内に残しています。物件マップの地図ライブラリ等は外部サービスを利用します。

## 共通ナビゲーション

すべてのツール画面上部に、同じデザインのナビゲーションバーを配置しています。

- **「← メイン画面」**：ルートの `index.html` に戻ります。
- PC・スマートフォンの両方に対応しています。
- ナビゲーションは画面上部に固定され、ページをスクロールしても利用できます。
- 物件比較用マップツールには **「CSV作成ツールへ →」** を追加しています。
- 物件CSV作成ツールには **「物件マップへ →」** を追加しています。
- 物件比較用マップツールのスマートフォン表示では、既存の地図／物件情報の表示切替機能を維持しています。

## 物件CSV作成ツールについて

物件CSV作成ツールでは、手入力またはSUUMOのURLを使って物件データを作成できます。URLから取得するモードでは、取得元の掲載URLもCSVのURL列に含める仕様です。

物件比較用マップツールへCSVを取り込むことで、物件情報・価格・メモ・掲載URLをまとめて管理できます。


## データ保存について

物件比較用マップツールの登録データは、基本的に利用中のブラウザのローカルストレージへ保存されます。別の端末・ブラウザには自動同期されないため、必要に応じてCSVでバックアップしてください。
