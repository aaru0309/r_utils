# HTML便利ツール

個人用HTMLツールをまとめた静的サイトです。ビルド工程は不要で、GitHub Pagesなどの静的ホスティングにそのまま配置できます。

## 収録ツール

- 予定作成ツール
- 費用集計ツール
- 単価比較計算ツール
- 物件比較用マップツール
- 物件CSV作成ツール

## フォルダー構成

```text
index.html                         # ツール一覧・GitHub Pagesの入口
予定作成ツールフォルダ/
├─ 予定作成ツール.html
├─ css/style.css
└─ js/app.js
費用集計ツール/
├─ 費用集計ツール.html
├─ css/style.css
└─ js/app.js
単価比較計算ツール/
├─ 単価比較計算ツール.html
├─ css/style.css
└─ js/app.js
物件比較用マップツール/
├─ 物件比較用マップツール.html
├─ css/style.css
└─ js/
   ├─ app.js
   └─ backup.js
物件CSV作成ツール/
├─ 物件CSV作成ツール.html
├─ css/style.css
└─ js/app.js
README.md
```

各ツールのHTMLに埋め込まれていた主要なCSSとJavaScriptは別ファイルに分けています。動作に必要な一部の動的な `style` 属性や、共通ナビゲーション用の小さなCSSはHTML内に残しています。物件マップの地図ライブラリ等は外部サービスを利用します。

## 共通ナビゲーション

すべてのツール画面上部に、同じデザインのナビゲーションバーを配置しています。

- **「← メイン画面」**：ルートの `index.html` に戻ります。
- PC・スマートフォンの両方に対応しています。
- ナビゲーションは画面上部に固定され、ページをスクロールしても利用できます。
- 物件比較用マップツールには **「CSV作成ツールへ →」** を追加しています。
- 物件CSV作成ツールには **「物件マップへ →」** を追加しています。
- 物件比較用マップツールのスマートフォン表示では、既存の地図／物件情報の表示切替機能を維持しています。

## 物件CSV作成ツールについて

物件CSV作成ツールでは、手入力またはSUUMOのURLを使って物件データを作成できます。URLから取得するモードでは、取得元の掲載URLもCSVのURL列に含める仕様です。

物件比較用マップツールへCSVを取り込むことで、物件情報・価格・メモ・掲載URLをまとめて管理できます。

## 公開方法

GitHub Pagesで公開する場合は、フォルダー構成を変更せずにリポジトリへ配置してください。ルートの `index.html` がメイン画面です。

各ツールの「← メイン画面」は `../index.html` への相対リンクで動作するため、各ツールフォルダーと `index.html` の位置関係を変更しないでください。

## データ保存について

物件比較用マップツールの登録データは、基本的に利用中のブラウザのローカルストレージへ保存されます。別の端末・ブラウザには自動同期されないため、必要に応じてCSVでバックアップしてください。

## 物件比較用マップツール：地図表示モード

物件比較用マップツールに、次の地図表示モードを追加しています。

- **ハザードモード**
  - 洪水（想定最大規模）
  - 高潮
  - 津波
  - 土砂災害
  - 国土交通省・国土地理院の「重ねるハザードマップ」で公開されているタイルデータを地図上に重ねて表示します。
  - 土砂災害は、土石流・急傾斜地の崩壊・地すべりの3レイヤーを重ねて表示します。
  - 地域によってデータが未整備・未掲載の場合があります。最終確認は公式ハザードマップや自治体の公開資料を利用してください。

- **周辺施設モード**
  - スーパー
  - 郵便局・郵便ポスト
  - 学校
  - コンビニ
  - 現在の地図中心から約2km以内の施設をOpenStreetMap / Overpass APIから取得し、地図上にアイコン表示します。
  - 地図を移動した後は「この位置で再検索」を押すと、その地点周辺の施設を再取得します。
  - 施設情報はOpenStreetMapの登録状況に依存するため、すべての施設が掲載されているとは限りません。

### 通信について

ハザードマップ、周辺施設、背景地図、住所検索はいずれも外部サービスからデータを取得するため、インターネット接続が必要です。

## 物件比較用マップツール：UI改善

- 「物件一覧・メモ」はPC・スマートフォン共通でトグル開閉できます。
  - 「物件一覧を閉じる」で地図を広く表示
  - 「物件一覧を開く」で再表示
- ハザードモードでは、選択中のハザード種別に応じて地図上に凡例を表示します。
  - 洪水・高潮・津波：浸水深の色分け目安
  - 土砂災害：警戒区域・特別警戒区域
- 地図左上の物件件数表示を右へ移動し、Leafletの拡大・縮小ボタンと重ならないようにしています。

※ ハザード凡例は見やすさのための目安表示です。最終確認はハザードマップポータルサイトや各自治体の公式資料で行ってください。

### ハザード凡例の表示

ハザード凡例は地図を隠しすぎないようにコンパクト化しています。

- 凡例の横幅を従来のおよそ半分に縮小
- 色チップとレベル表示は不透明のまま維持
- タイトル・背景・補足説明は半透明にして、背後の地図が見えるように調整
